Naganoor Village App — setup
============================

1) Install Flutter and run:
   flutter pub get

2) Supabase configuration (local, not committed):
   - Copy dart_defines.example.json to dart_defines.json
   - Fill in SUPABASE_URL and SUPABASE_ANON_KEY
   - dart_defines.json is gitignored — do not commit real keys

3) Run on Chrome with Supabase:
   flutter run -d chrome --dart-define-from-file=dart_defines.json

   Or:
   .\scripts\run_chrome.ps1

4) Apply database schema (first time only):
   Supabase Dashboard → SQL Editor → run supabase/schema.sql

5) Create an admin user:
   - Dashboard → Authentication → Users → Add user
   - SQL Editor:
     update public.users set role = 'admin' where email = 'your-admin@email.com';

6) Admin sign-in in the app:
   News tab → shield icon → email + password

7) Optional Maps:
   Add MAPS_API_KEY to dart_defines.json

Environment keys (dart_defines.json):
- SUPABASE_URL
- SUPABASE_ANON_KEY
- MAPS_API_KEY (optional)
